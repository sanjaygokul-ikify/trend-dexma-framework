# Contributing to Dexma Framework

The Dexma Framework is an open-source project, and we welcome contributions from the community. To contribute, follow these steps:
1. Fork the repository: `git fork https://github.com/dexma-framework/dexma-framework.git`
2. Create a new branch: `git branch my-branch`
3. Make changes and commit: `git commit -m 'my changes'`
4. Push changes to fork: `git push origin my-branch`
5. Create pull request: `git pull-request my-branch`

## Contribution Guidelines
* Follow standard professional guidelines for code style and formatting
* Ensure all changes are properly tested and documented
* Keep changes focused on a single feature or bug fix
